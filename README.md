# partition-block-uniformity

This repository contains code for numerical experiments on the partition function
\(p(n)\) modulo \(\ell=2,3,5\).

## Files

- `pmod_235_ntt.cpp`  
  Generates the residue sequence
  \[
  p(0),p(1),\ldots,p(N)\pmod{\ell}
  \]
  using Euler's pentagonal number theorem, Newton iteration, and the number-theoretic transform.

- `pmod_experiments_general.py`  
  Runs Pearson chi-square tests, missing-word experiments, and classifier two-sample tests.

## Requirements

### C++

A C++17 compiler is required.

### Python

Install the required Python packages:

```bash
python -m pip install numpy scipy mpmath torch scikit-learn
```

The packages `torch` and `scikit-learn` are needed only for the
classifier experiments.

## 1. Generate the residue data

Compile the C++ program:

```bash
g++ -O3 -std=c++17 pmod_235_ntt.cpp -o pmod_235_ntt
```

On Windows with MinGW:

```powershell
g++ -O3 -std=c++17 .\pmod_235_ntt.cpp -o .\pmod_235_ntt.exe
```

The program has the following form:

```text
pmod_235_ntt <ell> [N] [output_file]
```

For example, to generate \(p(n)\bmod 3\) for \(0\le n\le 10^8\):

### Linux or macOS

```bash
./pmod_235_ntt 3 100000000 pmod3_N1e8.txt
```

### Windows PowerShell

```powershell
.\pmod_235_ntt.exe 3 100000000 pmod3_N1e8.txt
```

Similarly, the data modulo \(2\) and \(5\) can be generated by:

```powershell
.\pmod_235_ntt.exe 2 100000000 pmod2_N1e8.txt
.\pmod_235_ntt.exe 5 100000000 pmod5_N1e8.txt
```

The output consists of comma-separated residues.

For a quick test, use a smaller value of \(N\):

```powershell
.\pmod_235_ntt.exe 3 100000 pmod3_test.txt
```

## 2. Run the Pearson experiments

For \(\ell=3\):

```powershell
python .\pmod_experiments_general.py --ell 3 --data .\pmod3_N1e8.txt chi2
```

The default Pearson ranges are:

- \(\ell=2\): \(1\le m\le19\)
- \(\ell=3\): \(1\le m\le12\)
- \(\ell=5\): \(1\le m\le9\)

A custom list of block lengths can be specified using `--m-list`:

```powershell
python .\pmod_experiments_general.py --ell 3 --data .\pmod3_N1e8.txt chi2 --m-list 1 5 11
```

## 3. Run the missing-word experiments

```powershell
python .\pmod_experiments_general.py --ell 2 --data .\pmod2_N1e8.txt missing
python .\pmod_experiments_general.py --ell 3 --data .\pmod3_N1e8.txt missing
python .\pmod_experiments_general.py --ell 5 --data .\pmod5_N1e8.txt missing
```

The default missing-word ranges are:

- \(\ell=2\): \(20\le m\le41\)
- \(\ell=3\): \(13\le m\le26\)
- \(\ell=5\): \(10\le m\le18\)

The expectation, variance, and Z-score are evaluated using
high-precision arithmetic.

A custom list can also be used:

```powershell
python .\pmod_experiments_general.py --ell 3 --data .\pmod3_N1e8.txt missing --m-list 14 16 18
```

## 4. Run the classifier experiments

### CNN

```powershell
python .\pmod_experiments_general.py --ell 3 --data .\pmod3_N1e8.txt c2st --model cnn
```

### Transformer

```powershell
python .\pmod_experiments_general.py --ell 3 --data .\pmod3_N1e8.txt c2st --model transformer
```

The default block lengths are:

- \(\ell=2\): \(m=50\)
- \(\ell=3\): \(m=32\)
- \(\ell=5\): \(m=22\)

To run the target sequence together with the control sequences:

```powershell
python .\pmod_experiments_general.py --ell 3 --data .\pmod3_N1e8.txt c2st --model cnn --controls target periodic biased digit_sum
```

The number of samples, epochs, batch size, and random seed can be changed:

```powershell
python .\pmod_experiments_general.py --ell 3 --data .\pmod3_N1e8.txt c2st --model cnn --samples 1000000 --epochs 2 --batch-size 4096 --seed 0
```

## Data files

The generated data files are not included in this repository because
they can be very large. They can be reproduced using
`pmod_235_ntt.cpp`.
